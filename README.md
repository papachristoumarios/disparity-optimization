# Disparity optimization

Code and data for reproducing the experiments in *Quantifying and Mitigating Consensus
Disparity in Social and Information Networks*. There are four entry points:

| Script | Produces |
|--------|----------|
| `link_recommendation.py` | Recommendation reweighing experiments (Figures 4, 5, 6, EC.2) |
| `opinion_seeding.py` | Opinion seeding experiments (Figures 3, EC.3, EC.4) |
| `sbm_sweep.py` | Disparity vs. polarization on stochastic block models (Figure 2 right, Figure EC.1) |
| `real_network_comparison.py` | Disparity vs. polarization on eleven real networks (Figure 7, Table EC.2) |

`illustration.py` draws the Polblogs panels of Figure 2, and `disparity.ipynb` contains the
same logic as the drivers in exploratory form. Figure 1 is a hand-drawn schematic and is not
generated by code.

## Setup

Use Python 3.11 or newer. From the repository root:

```bash
conda create -n disparity-optimization python=3.11
conda activate disparity-optimization
pip install -r requirements.txt
```

Experiment 9 of `link_recommendation.py` (the predictive-model experiment, Figure 6) trains
node embeddings with `--embedding_type node2vec`, which additionally requires the
`karateclub` package (`pip install karateclub`). All other experiments run with the pinned
requirements only.

## Data

Graphs and opinions live under `data/`. Each dataset directory contains:

- `edges.txt` — two or three whitespace-separated columns: `u v` or `u v weight`
- `opinions.txt` — two columns: `node_id opinion`; for datasets with a ground-truth group
  attribute the opinion is the group label in `{-1, +1}`

Bundled datasets and their nominal group structure (user counts are for the largest
connected component, which is what all experiments use):

| Directory | Users | Nominal groups | Source |
|-----------|-------|----------------|--------|
| `polblogs` | 1,222 | liberal / conservative (ground truth) | Adamic and Glance (2005) |
| `reddit`, `twitter` | 553, 548 | spectral bisection | Chitra and Musco (2020) |
| `twitch-DE`, `-ENGB`, `-ES`, `-FR`, `-PTBR`, `-RU` | 1.9k–9.5k | mature-content flag (ground truth) | Rozemberczki, Allen, and Sarkar (2021); see `data/twitch/citing.txt` |
| `fb-Caltech36`, `fb-Swarthmore42` | 699, 1,517 | reported gender (ground truth) | Traud, Mucha, and Porter (2012) |

The Twitch and Facebook100 directories are generated from the raw releases kept under
`data/twitch/` and `data/facebook100/`:

```bash
(cd data/twitch && python preprocess.py)   # -> data/twitch-*/  (also writes embeddings.npy)
python data/facebook100/preprocess.py      # -> data/fb-*/  (drops users with no reported gender)
```

Both scripts are deterministic and reproduce the bundled files byte for byte.

### Disparity versus polarization

`sbm_sweep.py` (about ten seconds) and `real_network_comparison.py` (a few minutes; one dense
eigendecomposition per network) are standalone and write their CSVs and figures to
`figures/`. Both are deterministic given the seeds fixed in the scripts.

```bash
python sbm_sweep.py
python real_network_comparison.py
python real_network_comparison.py --from-csv   # re-draw figure and table from the saved CSV
```

### Useful CLI flags

`link_recommendation.py` and `opinion_seeding.py` accept:

| Flag | Default | Description |
|------|---------|-------------|
| `--experiment_list` | `1` | Experiment ID(s), ranges (`4-6`), or `all` |
| `--size` | `all` | `small`/`all`: Polblogs, Reddit, Twitter (the paper's setting); `large` adds the Twitch networks |
| `--out-dir` | `figures` | Directory for CSV/PDF outputs |
| `--seed` | `0` | Random seed |
| `--cached_results` | off | Skip computation; rebuild plots from existing CSVs in `--out-dir` |
| `--s_type` | `actual` | Opinion vector: `actual` or `adversarial` (link experiments) |

`link_recommendation.py` also exposes `--batch_size`, `--rho`, `--eps`, and
`--embedding_type`; `opinion_seeding.py` exposes `--b` (budget) and `--ridge`
(regularization).

### Running the experiments on a cluster with SLURM

`scripts/run_all_experiments.sh` submits the experiments used in the paper with
`--size small`. The script creates `logs/` and `figures/` before submitting.

```bash
bash scripts/run_all_experiments.sh
```

To run one batch job manually:

```bash
mkdir -p logs figures
sbatch scripts/run_link_experiments.sh 3 small      # link experiment 3
sbatch scripts/run_seeding_experiments.sh 1 small   # opinion seeding experiment 1
```
